# PopTube Kids - Video Gallery UI

A simple, colorful video gallery interface inspired by YouTube Kids. Built this using just clean HTML and CSS—no bulky frameworks or extra libraries. 

## Features

* **Kid-Friendly Theme:** Used a bright color palette (bubblegum pink, sunshine yellow, sky blue) with big rounded shapes and playful fonts to make it inviting for kids.
* **Tilted Card Effect:** Added a subtle tilt to the video cards (`rotate` shifting on odd/even items). When you hover over them, they straighten up and lift smoothly.
* **Responsive Grid:** The video section uses CSS Grid, so it scales down nicely on mobile screens and expands on desktop without breaking.
* **Clean Code:** Kept everything organized with CSS variables for easy color customization later.

## Tech Used

* HTML5 (Structural markup)
* CSS3 (Flexbox, Grid, Custom Properties)
* Google Fonts (Baloo 2 for headings, Nunito for body text)

## Getting Started

1. Copy the code into a file named `index.html` on your computer.
2. Double-click or open the file in any web browser (Chrome, Safari, Edge) to run it locally.
